# Instructions for AI contributors (Claude, ChatGPT/Codex, others)
- This is an INDEX repository: it only lists d2c tools. Code lives in each `d2c-<tool>` repository.
- Add a tool to the table only when its repository has working code, offline tests and a README. Use honest status words (early / beta / stable).
- Public repository: never add private business names, customer data, keys, account configuration or links to private systems.
- Work on a branch and open a pull request; Claude reviews, the owner merges. Add a dated line to CHANGELOG.md.
